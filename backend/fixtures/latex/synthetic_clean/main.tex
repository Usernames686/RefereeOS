\begin{abstract}
We introduce SparseCellNet, a lightweight classifier for single-cell state assignment from compact gene panels. On a held-out benchmark of 1,200 cells, SparseCellNet improves macro F1 from 0.80 to 0.87 compared with a logistic-regression baseline while using 35 percent fewer features.
\end{abstract}

\section{Main Claims}
\begin{itemize}
\item SparseCellNet improves macro F1 by 0.07 over the baseline on a held-out test split.
\item Feature pruning reduces the panel size by 35 percent without reducing macro F1 below 0.86.
\item The method is practical for low-resource clinical screening workflows.
\end{itemize}
